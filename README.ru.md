# Ядро Spec256 для Karabas Go / Mini / Mini G

[English version](README.md)

ZX Spectrum 48K, который в железе играет в игры проекта [Spec256](https://en.wikipedia.org/wiki/Spec256)
в 256 цветах. Ядро для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25).

Игра Spec256 — это обычная игра для Спектрума плюс вторая копия её памяти, где на каждую точку
приходится 8 бит. Игра работает как обычно, а каждый байт, который она переносит, сдвигает или
складывает, точно так же переносится, сдвигается и складывается в 8 битовых плоскостях — вместе
они дают картинку в 256 цветах. Ядро делает это одним Z80 и 64-битным «SIMD»-блоком рядом с ним:
8 графических линий повторяют тракт данных Z80 (регистры, АЛУ) по управляющим сигналам основного
процессора. Как это устроено, описано в `docs/SIMD.md`.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `spec256.kg1` | VGA, 640x480 60 Гц | ЦАП I2S (PCM5102), выход бипера |
| Karabas Mini | `spec256.kg2` | HDMI, 640x480 60 Гц | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `spec256.kg3` | HDMI, 640x480 60 Гц | HDMI, ЦАП I2S |

Файлы ядер лежат в `src/`. Ядро для Mini G проверено на плате; ядра для Go и Mini собраны так же,
но на своих платах ещё не проверялись.

## Что умеет

- **Графика Spec256:** память игры и её 8 битовых плоскостей, палитра игры (`.PAL`) или
  стандартная палитра Spec256 (как в эмуляторе GZX), графика ПЗУ игры (`.GFB`). Цвета 0 и 0xFF
  выводятся по правилам эмулятора ZX-Poly (`.CFG` игры: PAPER / INK из атрибутов, смешивание с
  цветом атрибута); пункт OSD **Colour 0/FF** может это поменять.
- **Фоновые картинки** (`.B00`...): цвет 0 показывает картинку, её выбирают правила `.CFG` по ходу
  игры; картинки хранятся в SDRAM платы.
- **GFX 256** в меню OSD в любой момент переключает между картинкой в 256 цветах и обычной
  картинкой Спектрума.
- **Компьютер:** Спектрум 48K, Z80 на 3,5 МГц, ПЗУ 48K. Кадровое прерывание идёт от кадра VGA
  (60 Гц), поэтому игры идут чуть быстрее, чем на Спектруме с 50 Гц.
- **Звук:** бипер и AY-3-8910 на портах Спектрума 128 (#FFFD / #BFFD), стерео ABC, ACB или моно;
  индикаторы уровня на плате получают уровень звука.
- **Управление:** USB-клавиатура; два джойстика (джойстики платы или USB-геймпады) как Kempston,
  Sinclair 1, Sinclair 2, Cursor, QAOPM или QAOPS.
- **Загрузка:** игра — это один файл `.256` с SD-карты, он передаётся в ядро быстрыми пакетами
  (burst).

Чего пока нет:

- Расширений Spec256 для 128K (`.GF0`...`.GF7`, `.GFA`), магнитофона, сохранения игры.

## Как начать

1. Скопируйте `spec256.kg1` (Go), `spec256.kg2` (Mini) или `spec256.kg3` (Mini G) в корень
   SD-карты платы.
2. Положите игры `.256` на SD-карту (две есть в `src/games`, как сделать другие — в разделе
   [Игры](#игры)).
3. Выберите Spec256 в меню ядер. Спектрум запускается со своим ПЗУ.
4. Откройте OSD (**Menu+Esc**) и выберите игру в пункте **Snapshot** (или нажмите **Menu+T**).
   Игра запускается сразу после загрузки.

«Menu» — это клавиша Windows на клавиатуре.

## Меню OSD

**Menu+Esc** открывает и закрывает меню.

| Пункт | Значения | Клавиши |
|---|---|---|
| Snapshot | игра `.256` | Menu+T |
| Joystick L | Kempston / Sinclair1 / Sinclair2 / Cursor / QAOPM / QAOPS | Menu+J |
| Joystick R | то же | Menu+R |
| GFX 256 | Off / On: обычная картинка или 256 цветов | Menu+V |
| Colour 0/FF | Auto: как в `.CFG` игры; Attr: цвет 0 — PAPER, 0xFF — INK; Palette: оба из палитры; Pixel: 0xFF — обычная точка Спектрума | Menu+C |
| AY mode | ABC / ACB / Mono | Menu+A |
| Pause | Off / On | Menu+P |
| NMI | NMI процессора | Menu+F12 |
| Reset | сброс Спектрума | Ctrl+Alt+Del |

## Клавиатура

USB-клавиатура работает как клавиатура Спектрума. Shift — CAPS SHIFT, Ctrl — SYMBOL SHIFT, Alt и
Caps Lock — оба сразу (расширенный режим). Стрелки — CAPS SHIFT+5...8, Backspace — DELETE
(CAPS SHIFT+0), Esc — BREAK (CAPS SHIFT+SPACE), клавиши знаков препинания набирают то, что на них
нарисовано (например, `;` — SYMBOL SHIFT+O).

## Игры

Снапшот Спектрума 48K (`NAME.SNA`, 49179 байт) и его графика Spec256 (`NAME.GFX`, 393216 байт)
превращаются в один файл `.256` для ядра. В наборах игр Spec256 есть оба файла с одним именем.
Конвертер — `spec256/spec256.py` из
[karabas-go-tools](https://github.com/andykarpov/karabas-go-tools) (здесь `src/games/spec256.py` —
ссылка на него):

```
python3 spec256.py EXOLON.SNA
```

Он читает `EXOLON.SNA` и лежащий рядом `EXOLON.GFX` и пишет `EXOLON.256`; остальные файлы набора с
тем же именем добавляются, если они есть: `.PAL` (палитра), `.CFG` (правила цветов и фонов), `.GFB`
(графика ПЗУ), `.B00`...`.B99` (фоны). Регистр букв в именах не важен. `--plain` пишет старый
формат без них.

Файл `.256`: 48K памяти снапшота, затем для каждого адреса 8 битовых плоскостей (бит k плоскости p
— бит p цвета точки k), затем регистры снапшота; всего 442396 байт; дальше расширение `K256`
(настройки, палитра, правила, графика ПЗУ, фоны 256×192), описано в `docs/SIMD.md`, раздел 7.

## Сборка

Ядро собирается Xilinx ISE 14.7 под Linux: `cd src && make` (все три платы) или `make go`,
`make mini`, `make minig`; `make minig-report` показывает размер и тайминги. Модули плат — подмодуль
`modules/` ([karabas-go-modules](https://github.com/andykarpov/karabas-go-modules)): клонируйте с
`git clone --recursive` или выполните `git submodule update --init`. Для сборки рядом с этим
репозиторием нужен [karabas-go-tools](https://github.com/andykarpov/karabas-go-tools) (там
`make_core.py` и конвертер). Тесты процессора (ghdl) — в `src/sim`. Подробности устройства и тестов —
в `CLAUDE.md` и `docs/SIMD.md`.
